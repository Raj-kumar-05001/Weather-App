# 🌦️ Weather App

A responsive weather application that provides real-time weather updates for any city. Users can search for a location and instantly view weather details like temperature, humidity, wind speed, and current weather conditions.

---

## 🚀 Live Demo

🔗 Live Website: https://raj-kumar-05001.github.io/Weather-App/

---

## 📌 Features

✅ Search weather by city name  
✅ Real-time weather updates  
✅ Displays temperature  
✅ Shows humidity levels  
✅ Wind speed information  
✅ Dynamic weather conditions  
✅ Clean and responsive UI  
✅ Background weather visuals  

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- Weather API

## 🎯 How It Works

1. Enter a city name  
2. Click the search button  
3. App fetches real-time weather data  
4. Displays weather details instantly
